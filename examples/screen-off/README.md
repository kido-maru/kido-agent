# 見本: モニターの電源だけを切る(Windows)

起動ページのボタンで、PC は動かしたまま、モニターの電源だけを切る見本です。  
ゲームやサーバーを動かしたまま画面だけ暗くしたいときに使えます。  
この見本は Windows だけに対応しています。

| フォルダ | 何をするか |
|---|---|
| `windows/25_画面OFF` | モニターの電源を切る。マウスを動かすかキーを押すと点く |

## 使うとき

1. `windows/25_画面OFF` を、`KidoButtons` にコピーします。
2. 30 秒ほどで、起動ページに「画面OFF」のボタンが出ます。  
   PC にログインしているときだけ押せます。

## 「画面ロック」とのちがい

「画面ロック」は、サインイン画面に戻します。  
「画面OFF」は、ログインしたままモニターだけを消します。

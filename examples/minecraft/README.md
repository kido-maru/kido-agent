# 見本: マイクラのサーバーを起動・停止する

起動ページのボタンで、PC のマイクラ(Java 版)のサーバーを立ち上げたり止めたりする見本です。  
使うときは、フォルダを `KidoButtons` にコピーして、中のスクリプトを自分のサーバーに合わせて書き換えます。

| フォルダ | 何をするか |
|---|---|
| `mac-linux/60_マイクラ起動` | tmux の中でサーバーを起動する。Linux ではログインしていなくても使える(Mac はログインしてから) |
| `mac-linux/61_マイクラ停止` | サーバーに `stop` を打ち、ワールドを保存してから止める |
| `windows/60_マイクラ起動` | 窓でサーバーを起動する。ログインしてから押す |

## Mac・Linux

1. tmux を入れます。
   - Mac: `brew install tmux`
   - Ubuntu: `sudo apt install tmux`
2. `mac-linux` の中の 2 つのフォルダを、`~/KidoButtons` にコピーします。
3. `60_マイクラ起動/start.sh` の `SERVER_DIR`(サーバーのフォルダ)と `START`(起動のコマンド)を書き換えます。
4. 30 秒ほどで、起動ページに「マイクラ起動」「マイクラ停止」のボタンが出ます。

### サーバーのようすを見る

端末で `tmux attach -t mc` を実行すると、サーバーのコンソールが開きます。  
コマンドもそのまま打てます。

- 抜けるときは `Ctrl+b` を押してから `d` を押します(サーバーは動き続けます)
- `Ctrl+c` は押さないでください。サーバーが保存せずに止まります

### 止まらないとき

「マイクラ停止」は 12 秒待っても止まらなければ、起動ページに「失敗しました」と出します。  
ワールドが大きくて保存に時間がかかるときは、少し待ってから `tmux attach -t mc` で様子を見てください。

## Windows

1. `windows/60_マイクラ起動` を、`KidoButtons` にコピーします。
2. `start.bat` の `cd` の行(サーバーのフォルダ)と `java` の行(起動のコマンド)を書き換えます。  
   `.bat` の中に日本語を書くと動かないことがあるので、英数字だけで書いてください。
3. PC にログインしてから、起動ページで「マイクラ起動」を押します。  
   サーバーの窓が開きます。止めるときは、窓に `stop` と打ちます。

Windows では、ログインする前に起動したものの窓は、あとからログインしても見えません。  
中を見られず止めることもできなくなるので、この見本は `require_login = true` でログインしてからだけ押せるようにしています。

## API から呼ぶとき

取り決め v2 では `POST /v1/run` の `id` に `60_マイクラ起動` のような完全な ID、
または `マイクラ起動` のように番号を除いた短い名前を指定できます。完全な ID が優先です。
番号だけを変えても短い名前はそのまま使えます。署名には、要求に書いた `id` をそのまま使います。
同じ短い名前のフォルダが複数あると、一覧では両方に `x:1` が付き、短い名前での実行は
`broken_action` になります。重複だけなら完全な ID では呼べます。`kido-agent status` で確かめてください。

一覧は `{"v":"…","a":[{"id":"60_マイクラ起動","n":"マイクラ起動","ic":"pickaxe"}]}`
の形です。`confirm = true` なら `cf:1`、ログインが必要で押せないときは `l:1` が付きます。
`kido.toml` のキー名は変わりません。前回の版を `list` の `v` に渡すと、同じなら `same:1` だけを返します。
`run` は、停止のような `wait = true` の操作でも `ok`・`code` などの結果と一緒に一覧の版 `v` を返します。
署名と応答の詳しい形は [PROTOCOL.md](../../PROTOCOL.md) を参照してください。
